# 🏏 IPL Data Analysis Dashboard

An interactive Microsoft Excel dashboard developed to analyze Indian Premier League (IPL) match data and uncover meaningful insights into team performance, player statistics, venue trends, and tournament outcomes. The dashboard enables users to explore IPL data dynamically using Pivot Tables, Pivot Charts, slicers, and advanced Excel features.

---

## 📌 Project Overview

The objective of this project is to transform raw IPL match data into an interactive dashboard that helps users analyze tournament statistics and identify performance trends. The dashboard provides key insights into teams, players, venues, toss decisions, and match outcomes to support data-driven analysis.

---

## 🎯 Objectives

- Analyze IPL match and team performance across multiple seasons.
- Monitor important tournament KPIs.
- Compare team performance across different venues.
- Evaluate the impact of toss decisions on match results.
- Build an interactive dashboard for easy exploration of IPL statistics.
